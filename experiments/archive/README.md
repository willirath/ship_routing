# Archived Experiments

This directory contains historical tuning experiments that are kept for reference but are no longer actively maintained.

## Contents

- **tuning_001**: Initial hyperparameter tuning experiment
- **tuning_002**: Second iteration of tuning experiments with improved infrastructure

## Current Active Experiments

Active experiments are located in the parent directory (`experiments/`). These use the shared HTC infrastructure from `ship_routing.htc`.

## Note

These archived experiments may not work with the current codebase structure, as they were created before the introduction of the `ship_routing.htc` package. They are preserved for historical reference and can always be recovered from git history if needed.
